# Multi Agent 실행 로그 EDA 보고서

## 1. 질문과 출처
질문: 어떤 역할의 에이전트가 평균 지연시간이 가장 길며, 각 에이전트의 실행 횟수, 측정 건수, 평균·중앙값 지연시간 및 성공률은 어떤 의미를 가지는가? 또한 지연시간 데이터의 누락은 분석에 어떤 한계를 주는가?
출처: 본 자료는 AI 아카데미 2기 실습을 위한 수업용 합성 데이터로 실제 성능과 가격을 표시한 데이터가 아닙니다.

## 2. 정제 정책
- 중복된 데이터는 제거하고, 원본 데이터가 변경되지 않도록 복사해서 사용했다.
- 지연시간이 숫자가 아닌 값은 숫자로 변환하고, 변환할 수 없는 값은 결측치로 처리했다.
- 지연시간이 비어 있는 데이터는 임의로 삭제하지 않고, 평균과 중앙값을 계산할 때 제외했다.
- 성공 여부는 실행 상태가 ok인지 확인해서 구분했다.
- 정제한 데이터는 out/clean_runs.csv 파일로 저장했다.

## 4. 한계와 개선안
현재 나온 데이터 종류와 표본 수 만으로는 정확도가 낮기에 좀 더 많은 수의 표본과 더 다양한 종류의 데이터가 필요하다. 1개 이상의 한계와 이를 확인할 추가 데이터/실험. 관계를 인과로 단정하지 않는다.

## 5. 재현 및 개인 기여
실행 명령, 실제 환경, 실제 테스트 결과, 수행한 수정, 담당 역할.
